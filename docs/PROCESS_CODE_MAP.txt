SIMULATION, TRAINING AND ANALYSIS

Paths are relative to the package root. The project/ directory contains the
preparation and execution programs. Each studies/<study>/source or
source_snapshot directory contains the MATLAB sources used for that study.
Select one study's source tree at a time to avoid duplicate function names.

REPRODUCTION FROM PACKAGED DATA
  run_review                         Tables, saved-model predictions, figures
  run_review('evaluation')            PNN inference and 5000 object resamples
  run_review('online_statistics')     PCU/PCR statistics and 4000 stream resamples

The table entry recomputes errors and coverage from individual predictions,
including raw and common_clip outputs. It covers PNN, PSV, PSX, PBD, PCA,
and the PCU/PCR pooled, stream, block, terminal and retention summaries.

MAIN PAYLOAD ESTIMATION
Study: pnn_large_training_20261031_v1
  Preparation: project/prepare_pnn_run.m
  Workflow: run_pnn_job.m in the prepared source_snapshot
  Data generation: src/pnn_plan.m; src/pnn_generate_data.m
  Features: src/pnn_features.m; src/pnn_cache_dataset.m
  Training: src/pnn_train.m; src/pnn_nn_fit.m
  Prediction and evaluation: src/pnn_predict.m; src/pnn_evaluate.m

The workflow generates development data, trains and selects the models, then
generates and evaluates the test panel. The compact dataset supplies 12,000
training objects, 2,000 validation objects and 2,000 test objects observed under
four conditions. Feature-based retraining and a single-object generation
example are available through matlab/review_pnn_retrain.m and
matlab/review_simulate_example.m. Their README files give commands and settings.

PCU uses four drift scenarios, eight paired streams and four update blocks.
Unknown-object prediction precedes each reference update. PCR uses the same
observations. Prediction, update and stream-level tables support statistical
recomputation through run_review('online_statistics').

NEW SIMULATION CAMPAIGNS
Prepare new runs from project/ using distinct run names and writable output
directories. The PNN and PGAR preparation paths create new simulation runs.
Dependent workflows use the following inputs under project/results/<study>:
  PSV: PGAR configuration, PSF selected models and Lao baseline models
  PCU: PGAR development features/model, PRB configuration and retention probes
  PCR: PCU observations, PSV ridge initialization and retention probes
  PSX/PBD: PNN development features/models and parent study configuration
  PCA: Matched affine starting models and PSX/PBD evaluation inputs

Map these inputs into a new workspace before using the original job runners.
The package-relative review functions use the distributed data directly.
MATLAB private/ directories are part of the source layout. Robot geometry and
inertial constants are encoded in MATLAB; no external URDF or mesh is loaded.
