SOFTWARE REQUIREMENTS

Reference environment: MATLAB R2026a on Windows. The review functions use
package-relative paths. The JVM must be enabled for path handling and SHA256.
Use the reference MATLAB release for the closest numerical match and model
deserialization.

Descriptive CSV recomputation and figure reproduction require MATLAB;
functions such as prctile may require Statistics and Machine Learning Toolbox
on older releases.

Saved-model PNN inference requires Deep Learning Toolbox and Statistics and
Machine Learning Toolbox for dlnetwork and fitrnet model loading/prediction.
Feature-only PNN training uses those toolboxes and the dependencies invoked
by pnn_train. The supplied training configuration does not require a GPU.

Full simulation campaigns additionally use Optimization Toolbox, Robotics
System Toolbox and Parallel Computing Toolbox. See the prepare_* dependency
checks and PROCESS_CODE_MAP.txt before starting a full campaign.

Optional hardware-interface programs use MATLAB serialport or Python with
pyserial and the appropriate device driver. Hardware, a USB driver and a
power meter are not required by the offline review entries. Host-specific
launchers in project/scripts are not invoked by run_review.

Python 3 is optional for verify_package.py, which uses only the standard
library. MATLAB and its toolboxes require separately licensed installations.
