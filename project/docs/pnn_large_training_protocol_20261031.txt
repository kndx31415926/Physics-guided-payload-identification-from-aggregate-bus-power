PNN large-data neural/ridge study — prospective execution protocol
Version: pnn_large_training_v1, 2026-10-31
Status: freeze this file and all source code before the formal task starts.

Purpose and claim boundary
Test whether better residual scaling, a ridge skip connection, and conditioning on observable physical sensitivity improve mass and planar-COM estimation from aggregate bus power and original encoders. No performance advantage is assumed. This round is offline training and independent four-condition confirmation. Prospective online adaptation of the selected new architecture requires a subsequent separately frozen trajectory experiment; this run does not replace or relabel existing PCU/PCR results. No hardware claim, three-dimensional COM claim, or lifetime wear-error guarantee.

Data quantities and identity
12,000 distinct training objects, 2,000 distinct validation objects, and 2,000 new test objects. Train and validation each have one full eight-pose servo episode per object, balanced over nominal, mechanical, electrical, and combined families. Every test object is simulated in all four families, yielding 8,000 test episodes and 22,000 total episodes. Each object remains in one split. Noise, communication and nuisance draws are independent per trial; paired test comparisons are by object, not by shared noise. Counts include failed trials, which are retained and never replaced with convenient new draws.
Payload domain: m in [0.08,0.22] kg, cx in [0.05,0.19] m, cz in [-0.018,0.018] m. Physics solver bounds: [0.06,0.25] kg, [0.04,0.20] m, [-0.025,0.025] m. Full servo integration and eight-pose 22.6 s probe remain as configured. Host cadence is 50 ms; command and encoder-return delays each independently uniform from 10 to 15 ms, quantized by the existing 1 ms simulator. This is a new explicitly combined mismatch/jitter experiment, not a retrospective change to old PCU timing.
Object split seeds: 1410101,1410102,1410103. Sensor base14200000, communication base14400000, nuisance base14500000. Object ID base3000000. Network seeds1430101,1430102,1430103. Bootstrap seed1460101.
Mechanical perturbations use existing PSV link mass, link COM, friction and gain deviations, independently multiplied per component by U(0.5,1.5). Electrical absolute-torque and quartic-torque extra-loss coefficients are separately scaled by U(0.5,1.5) from the existing PSV prescription. Nominal has neither additional mechanism. Combined applies both. These are declared sensitivity models, not identified actual wear distributions. Training and confirmation sample the same declared family distributions independently; this is not a proof of extrapolation beyond them. Hidden nuisance factors and family labels are never predictor inputs.

Separation of development and confirmation
Freeze object plans, source, configuration, protocol and seeds before generation. Generate/cache train and validation first. Train and select exclusively from these data. Write model_bundle.mat, LOCKED_SELECTION_BEFORE_TEST.mat and a hash-bearing MODEL_LOCK.json before test generation. Test generation and feature caching verify this lock. A model or code change after test examination starts a new development study; do not reuse its test result as a new independent confirmation.
Previously completed PSV/PCU/PCR observations and their outcomes motivated this protocol. No previous test records enter this run's training or confirmation.

Observation and feature interfaces
The physical teacher remains the six-pose inverse with two checks. X13 contains the previous 13 observable features. Xaug has 52 features: X13 plus 24 scaled Jacobian entries, 8 power SDs, 3 regularized GN corrections, 3 singular-value summaries and 1 condition summary. GN damping is0.001 in parameter-range-normalized, noise-whitened coordinates. All are computed under the nominal available model/calibration from recorded q/P; no true torque, mass, nuisance or simulator state is input. The final learning estimators consume all eight residuals; the teacher's two check poses are not independent validation of the final estimator.
Include an independent full-eight-pose physical inverse baseline. Physical-baseline failure does not remove an otherwise usable learning row. Common learner training eligibility requires finite X13, Xaug, base and target; finite predictions from teacher-rejected examples remain scored, with acceptance reported separately. Each of the four families must retain at least100 eligible training and100 eligible validation examples; failure is an explicit study failure, not a reduced-condition success.
Only steady-state information is used. The current simulator links payload inertia deterministically to mass/COM; transient learning would require a different shape/inertia-independent study and is excluded here.

Estimators and fixed search budget
1. Physics6 and Physics8.
2. Ridge13; ridgeAug; interaction ridge with all 52 features plus 91 quadratic products of the first13 (143 predictors).
3. OldNN13 anchor: one hidden layer8 tanh units, lambda0.001, original response scales[0.14,0.14,0.036],800 LBFGS iterations,validation patience30; average all three fixed seeds.
4. ScaledNN13; ridgeSkipNN13; ridgeSkipNNaug. Each has six candidates: layers[16] or[32,16], nonlinear penalty1e-6,1e-4 or1e-2. Each candidate averages all three fixed seeds before validation scoring; no seed selection. Hidden weights normally initialized, final nonlinear output initially zero. The skip branch reproduces its selected ridge exactly at initialization and is frozen during nonlinear fitting. Candidate skip strengths alpha in{0,0.25,0.5,0.75,1} are selected on validation only, including the explicit ridge fallback.
Ridge methods independently search lambda=10.^(-7:0). Ridge13 chooses minimum validation (massMAE/1g + mean planarCOM distance/1mm). Other methods minimize the largest of eight ratios relative to the selected Ridge13: massMAE and planarCOM mean distance in each of four validation families; mean ratio breaks ties, then fixed candidate order. All ratios and component metrics are retained. New primary NN family is selected by the same validation rule before locking; all comparison methods remain reported.
Residual amplitude preprocessing uses training data only, with physical-unit floor1e-5 for each output. It is a numerical parameterization, not an implicit change to the physical loss weighting. Inputs are standardized using training data only. New neural optimization uses physical mass and isotropic planar-COM scales1g/1mm, a smooth absolute/distance loss with dimensionless smoothing0.1, plus the declared nonlinear L2 penalty. Exact formulas and parameter sets are stored with candidate metadata. Ridge retains squared-error fitting; therefore between-family gains concern the complete estimator and training recipe, and cannot be attributed exclusively to nonlinear capacity. A same-smooth-loss linear estimator is not part of this run.
Adam: batch256,learning rate0.001,beta1=0.9,beta2=0.999,epsilon1e-8,max1500 epochs,validation patience150. Per-seed epoch retention/early stop uses smooth physical validation loss; final ensemble/candidate selection uses the minimax ratios. This distinction is explicit. Initial epoch0 can remain the retained predictor. Reaching an epoch limit is reported as such, not called convergence. Early stopping and all training/validation histories are saved.

Checkpoint and resource contract
Six MATLAB process workers, one compute thread each, for trajectory and feature stages; one CPU training process for model optimization. No forced restart, no global power-plan or OS-update changes. Existing independent Task Scheduler worker temporarily inhibits automatic sleep while running.
Data: immutable per-trial records and per-trial feature records with identity, seed, plan signature and SHA256 seal; atomic commits and recovery of interrupted renames. Committed failed simulations remain failed records. Corrupt or unknown-identity records cause explicit failure; never silently regenerate or overwrite them.
Training: save current network, Adam first/second moments, optimizer iteration, epoch, RNG, normalization, best network/state, patience state and history every5 completed epochs. Resume from a verified checkpoint; at most the work since the previous checkpoint repeats. Preserve at least one previously valid checkpoint so interruption during replacement is recoverable. Record immutable completed candidate identities and results. The old fitrnet anchor can checkpoint at completed-seed granularity only; an interrupted single seed restarts deterministically, not from internal LBFGS iteration.
Scheduled task is independent of the launching application. It resumes after this Windows user logs in following a reboot (30 s login trigger delay). No execution while the machine is powered off or before the required user login. Manual Stop pauses auto-resume; Resume explicitly releases the pause. Existing live tasks/processes/locks prevent duplicate workers. Completed runs do not relaunch. Scientific failures preserve records and require diagnosis rather than endless automatic retries.

Confirmation outputs and statistics
For every method/family report planned N, finite N, accepted N, failures, clipped N, raw massMAE, massRMSE, mass95th percentile, mean planarCOM distance, COM95th percentile and worst errors. Retain raw predictions and common-bound-clipped predictions separately; finite rejected predictions remain in the primary all-finite statistics. Missing pairs require coverage disclosure and cannot support a blanket superiority conclusion.
Paired bootstrap by independent test object,5000 replicates. All four conditions of an object travel together when applicable. Pairwise differences are new method minus Ridge13 (negative favors new method). Ordinary95% two-sided intervals for all comparisons are descriptive. For the validation-selected primary NN, use one-sided Bonferroni-adjusted upper limits at quantile1-0.05/8=0.99375 for the eight condition/metric endpoints. Strict overall superiority is reported only if all eight upper limits are below zero, all planned pairs are finite, and accepted coverage is not reduced. No claim of superiority in runtime, simplicity or calibration cost follows from this endpoint check. No noninferiority/equivalence claim is made from an interval merely crossing zero. No final-result-dependent change to this rule.
The same paired differences are also reported against ridgeAug and interactionRidge. A stronger claim against all three ridge comparators requires all24 primary-network endpoints to pass one-sided Bonferroni upper limits at1-0.05/24, with full finite pairing and no lower acceptance. These percentile-bootstrap limits are approximate sampling uncertainty, not a universal or finite-sample mathematical guarantee. Passing the eight-endpoint Ridge13 comparison alone does not support a claim against all ridge variants. Nonfinite predictions remain nonfinite under common clipping; clipping cannot turn a failed result into a valid one.
All exact hashes, selected hyperparameters, normalization, data identities, failures and run attempts are preserved. Existing datasets are not overwritten. New numerical results are checked against their recorded inputs.
